The old `index.html` placeholder is gone; this site is now built with
[Hugo](https://gohugo.io/) and the [Paper](https://github.com/nanxiaobei/hugo-paper)
theme, and deployed to GitHub Pages by GitHub Actions on every push to `main`.

To add a post:

```sh
hugo new posts/my-post.md
```

Then drop `draft: true` from the front matter when it's ready to ship.
